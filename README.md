# 🛍️ Digital Store - Projeto Front-end

Este é o projeto final do curso de Front-end organizada pela instituição Geração Tech 4.0. A aplicação é uma loja virtual completa (e-commerce) inspirada no design do Figma "Digital Store", desenvolvida para aplicar os conhecimentos de React, componentização, rotas e estilização.

## 🚀 Tecnologias Utilizadas

- **[React](https://reactjs.org/)**: Biblioteca JavaScript para construção de interfaces.
- **[Vite](https://vitejs.dev/)**: Ferramenta de build e servidor de desenvolvimento super rápido.
- **[React Router DOM](https://reactrouter.com/)**: Para gerenciar a navegação entre as páginas (Home, Listagem e Detalhes).
- **[Tailwind CSS](https://tailwindcss.com/)**: Framework de estilização para criar o layout de forma ágil e responsiva.

## 📱 Funcionalidades

- **Header e Footer fixos**: Navegação presente em todas as páginas.
- **Página Inicial (Home)**: Banner principal e seção de coleções em destaque.
- **Listagem de Produtos**: Grid de produtos com barra lateral de filtros.
- **Detalhes do Produto**: Página individual com galeria de imagens, seleção de cores (interativa), tamanhos e botão de compra.
- **Produtos Relacionados**: Sugestões de produtos na página de detalhes.
- **Roteamento Dinâmico**: A página de produto carrega as informações corretas de acordo com o ID na URL.
